# Contributing

Thank you for your interest in improving the KDP Email Dashboard.

## Development

This is a static site (HTML / CSS / vanilla JS). No build tooling is required.

1. Fork and clone the repository.
2. Serve locally (`npx serve .` or any static server).
3. Edit `index.html`, `app.js`, or `styles.css`.
4. Keep changes focused; update `data/` only via the intended automation.

## Pull Requests

- Describe the change and the reason.
- Do not commit secrets or personal Gmail credentials.
- Prefer small, reviewable PRs.

## Security

Report vulnerabilities privately — see [SECURITY.md](SECURITY.md).

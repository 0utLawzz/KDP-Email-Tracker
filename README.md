# kdp-email-dashboard

Personal Amazon KDP email tracker for Bright Mindful Pages.

- `data/emails.json` — permanent history (Gmail message ID is the unique key)
- `data/state.json` — last successful automation checkpoint
- `index.html` / `app.js` / `styles.css` — GitHub Pages dashboard

Official KDP / Kindle Content Review inbound mail only. Replies and shopping mail are excluded.
